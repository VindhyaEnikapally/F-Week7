Important React Concepts Used

## 1. Components

Components are reusable blocks of UI.
Components used in the project:

* Header
* Footer
* Home
* ProductsList
* Product
* RootLayout

## 2. JSX
JSX allows writing HTML inside JavaScript.

## 3. Props
Props are used to pass data from parent component to child component.

## 4. useState Hook

`useState` is used to store and update data.

Used for:

* Product data
* Loading state
* Error handling

## 5. useEffect Hook

`useEffect` is used to perform side effects like API calls.

## 6. React Router DOM

Used for page navigation.

Methods used: createBrowserRouter()
Creates routing configuration.

### RouterProvider
Provides routing to the application.

### Outlet
Displays child routes.

### NavLink
Used for navigation links.

# JavaScript Methods Used
## map()
Used to display multiple items.

## filter()
Used to filter required data.

## async / await
Used for API calls.

## fetch()
Used to get API data.
